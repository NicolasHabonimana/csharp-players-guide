# The C# Player's Guide — My Challenge Solutions

My solutions to the programming challenges in *The C# Player's Guide* by RB Whitaker. I worked through these to learn C# from the basics up to enums and classes, before moving to bigger projects like my Unity game [Aura Run](https://github.com/NicolasHabonimana/aura-run).

| # | Challenge | Topics |
|---|-----------|--------|
| 01 | [The Triangle Farmer](01-the-triangle-farmer) | User input and a simple area calculation |
| 02 | [The Dominion of Kings](02-the-dominion-of-kings) | Variables and arithmetic |
| 03 | [The Defense of Consolas](03-the-defense-of-consolas) | Math and console output |
| 04 | [Repairing the Clocktower](04-repairing-the-clocktower) | `if` / `else` and the `%` operator |
| 05 | [Watchtower](05-watchtower) | Nested `if` conditions with x and y coordinates |
| 06 | [Buying Inventory](06-buying-inventory) | A numbered menu and a class with a constructor |
| 07 | [Discounted Inventory](07-discounted-inventory) | Extending the previous program with a discount rule |
| 08 | [The Prototype](08-the-prototype) | `while` loops and input validation |
| 09 | [The Magic Cannon](09-the-magic-cannon) | `for` loops and the `%` operator |
| 10 | [The Replicator of D'To](10-the-replicator-of-dto) | Arrays, loops and input validation |
| 11 | [Hunting the Manticore](11-hunting-the-manticore) | A small turn-based game with loops |
| 12 | [Simula's Test](12-simulas-test) | A chest state machine with `switch` and constructor chaining |
| 13 | [Simula's Soup](13-simulas-soup) | A class built from the user's menu choices |
| 14 | [Vin Fletcher's Arrows](14-vin-fletchers-arrows) | Classes, enums and methods |
| 15 | [The Properties of Arrows](15-the-properties-of-arrows) | Properties with getters and setters |
| 16 | [Vin's Trouble](16-vins-trouble) | Enums, `switch` and keeping the data inside the class |

## Run a challenge

You need the [.NET SDK](https://dotnet.microsoft.com/download). Open the `.sln` in any folder with Visual Studio or Rider, or run it from the project folder with `dotnet run`.
